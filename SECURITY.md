# Security Policy

## Supported versions

Security fixes are provided for the `main` branch and the latest released version of this provider. Older
releases are not supported.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Latest release | Yes |
| Earlier releases | No |

## Scope

Report vulnerabilities in this repository's provider code, credential handling, HTTP client, release
artifacts, and release or CI workflows.

Vulnerabilities in kintone itself or Terraform itself are outside this repository's scope. Report those to
the applicable upstream project or service provider.

## Reporting a vulnerability

Use GitHub Private Vulnerability Reporting for this repository. Do not report security vulnerabilities in a
public issue, pull request, discussion, or commit.

Do not include credentials, API tokens, private keys, passwords, or other secrets in public issues, pull
requests, logs, or workflow artifacts. Redact sensitive values from reproduction material. If a report
requires a secret to demonstrate impact, explain the requirement in the private report without sharing the
secret unless the maintainers explicitly provide a secure channel.

Include a clear description of the issue, affected versions, impact, reproduction steps or a proof of
concept, and any suggested remediation. Reports will be acknowledged, investigated, and coordinated
privately.
